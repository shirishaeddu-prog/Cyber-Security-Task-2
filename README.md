#Task 2: Phishing Email Analysis

 Objective
The objective of this task is to analyze a suspicious email and identify common phishing indicators.

 Tools Used
- Python
- Pydroid 3
- Regular Expressions (re)

 Email Sample
A sample suspicious email is included directly in the Python code.

The email contains:
- Suspicious sender address
- Urgent and threatening language
- Suspicious verification link
- Request for immediate account verification

 Phishing Indicators Identified

1. Suspicious Sender
The sender address contains a suspicious domain that uses `paypa1` instead of the legitimate spelling.

2. Urgent Language
The email uses words such as:
- Urgent
- Immediately
- 24 hours
- Blocked
- Suspended

This creates pressure on the user to act quickly.

3. Suspicious Link
The email contains a verification link that does not belong to the legitimate service.

4. Verification Request
The email asks the user to verify the account immediately.

 5. Possible Spoofing
The sender/domain appears designed to look similar to a trusted service.

How to Run

1. Open Pydroid 3.
2. Create a new Python file.
3. Copy the phishing email analysis code into the file.
4. Save the file.
5. Press the Run button.
6. Check the analysis results in the output.

 Expected Result

The program identifies the following phishing indicators:

- Suspicious sender/domain
- Urgent and threatening language
- Suspicious verification link
- Request for immediate account action

 Conclusion

The sample email contains multiple characteristics commonly associated with phishing. Users should avoid clicking suspicious links or providing personal information and should verify the sender through a trusted method.
